# Medu Neter — the Hieroglyph Typewriter

Type modern English and watch it become 3,000-year-old Egyptian hieroglyphs, with Egyptological transliteration, curated phrase translations, audio pronunciation, name cartouches, and shareable cards.

**Live demo:** https://mahmoudabdalhamid10-alt.github.io/medu-neter/

## Built with Kiro
Spec-driven development with Kiro CLI: requirements (EARS), design, and tasks in `.kiro/specs/medu-neter/`; steering in `.kiro/steering/product.md`. Kiro implemented the transliteration strip, phrase dictionary, and audio playback from the spec.

## Tech
Vanilla HTML/CSS/JS. No frameworks, no build step, no dependencies, fully client-side.
